# AI_Advent_Challenge_#9_Day6

Проект **Agent Sprout** — AI-агент с управлением контекстом через rolling-резюме.

## Механизм компрессии истории

Агент поддерживает два режима работы с контекстом:

| Режим | Описание |
|---|---|
| `full` | Вся история диалога отправляется в каждом запросе |
| `compressed` | Последние **N** сообщений хранятся «как есть», остальное сворачивается в краткое резюме каждые **M** сообщений |

### Как работает сжатие

1. Пользователь задаёт окно `keepRecent` (сколько последних сообщений хранить) и порог `summarizeEvery` (через сколько сообщений обновлять резюме).
2. Когда в истории накапливается ≥ `summarizeEvery` новых сообщений за пределами окна, агент вызывает ту же модель (с temperature=0) и просит её сжать этот кусок диалога в резюме.
3. Резюме сохраняется в `app/data/chat_history.json` вместе с историей.
4. В следующих запросах полная история заменяется конструкцией: **system prompt → резюме (как system) → последние N сообщений → вопрос**.

### Настройки в интерфейсе

- **Контекст:** переключатель `Полная история` / `Сжатие с резюме`
- **Хранить последних N сообщений:** размер окна (по умолчанию 6)
- **Сжимать каждые M сообщений:** порог обновления резюме (по умолчанию 10)
- Кнопка **Резюме** в шапке — просмотр текущего текста резюме и возможность сбросить
- Под каждым ответом — бейджи: число отправленных/всего сообщений и токены экономии

## Результаты сравнения (deepseek-v4-pro, 40-сообщенческая история)

| | Full | Compressed |
|---|---|---|
| prompt_tokens | 559 | 310 |
| Экономия | — | **44.5%** |
| Качество | Артём, Kotlin+Go, 1 августа | Артём, Kotlin+Go, 1 августа |
| Резюме | — | 608 tok (одноразово) |

Вывод: на истории из 40 сообщений компрессия экономит 44.5% промпт-токенов **без потери качества**. Резюме сохранило все факты: имя, стек, дедлайн, инфраструктуру. Стоимость генерации самого резюме (608 токенов) окупается на 3-4 полных запросах.

## Настройки агента

- **Выбор модели:** из `ai-public` и `nvidia` NIM
- **Промпт (роль):** Ассистент, Пошагово, Аналитик, Инженер, Критик
- **Параметры:** температура, Top_P, Frequency/Presence penalties
- **Лимиты:** токенов ответа, слов, размера вопроса
- **Формат ответа:** Текст (Markdown) или JSON
- **Глубина памяти:** сколько сообщений передаётся в контекст при full-режиме
- **Контекст:** режим работы с историей (full/compressed), размер окна, интервал сжатия

## Сохранение истории

История и резюме сохраняются в `app/data/chat_history.json` с атомарной записью. При перезапуске сервера диалог полностью восстанавливается.

## Архитектура

- `app/agent.py` — логика агента, компрессия, метрики
- `app/llm.py` — клиент к API (ai-public + nvidia)
- `app/store.py` — сохранение/загрузка состояния в JSON
- `app/server.py` — HTTP-сервер (статика + REST API)
- `web/` — фронтенд без сборки (HTML/CSS/JS)

Бэкенд на чистом Python, без NodeJS или Docker. Ключи из `~/.secrets` на клиент не попадают.
