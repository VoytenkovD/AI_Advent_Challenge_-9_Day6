# AI_Advent_Challenge_#9_Day6

Проект **Agent Sprout** — мощный одиночный AI-агент с полным контролем над поведением и параметрами генерации. 

Приложение отошло от концепции "3 колонок для сравнения". Теперь у вас есть **один полноэкранный чат** с агентом, который **помнит контекст** разговора. Справа открывается боковая панель для детальной настройки его логики.

## Что можно настроить:
- **Выбор модели:** Доступны все модели из `ai-public` и `nvidia` NIM.
- **Промпт (роль):** Ассистент, Пошагово, Аналитик, Инженер, Критик.
- **Параметры генерации:** Температура (0-2), Top_P.
- **Штрафы:** `Frequency Penalty` (штраф за повтор слов) и `Presence Penalty` (штраф за возврат к старым темам).
- **Лимиты:** Максимальное количество токенов, жесткий лимит слов, ограничение на размер вопроса.
- **Формат ответа:** Обычный текст (Markdown) или строгий JSON.
- **Глубина памяти:** Сколько последних сообщений отправляется модели вместе с новым запросом.

## Расход токенов
На верхней панели добавлена кнопка **📊 Расход токенов**. Она открывает сводную таблицу по суммарному потреблению токенов за текущую сессию (входные и выходные).

## Архитектура
Как и в предыдущие дни, бэкенд написан на чистом Python без использования NodeJS или Docker. 
Ключи доступа к моделям (из файлов `~/.secrets`) остаются исключительно на сервере и никогда не "светятся" на клиенте, в отличие от оригинального репозитория. Вся логика управления промптами и лимитами (Input Policy) вынесена в файл `agent.py`.

## Запуск

```bash
run.bat
```
Откроется <http://127.0.0.1:5182>.
